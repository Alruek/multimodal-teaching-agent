## 一、项目简介

本项目是一款面向高校教与学场景的多模态教学智能体。它基于腾讯 LearnBuddy 平台，深度融合大模型的多模态理解能力与 Web 前端技术，实现「上传教学素材 → 智能解析 → 结构化知识点 → 交互式答疑」的完整闭环，帮助师生快速把课件、讲义、截图转化为可学习、可追问的知识资产。

与大语言模型的简单问答不同，本作品的核心在于「真正理解教学资料」：把一个素材吃透、拆成清晰的知识点结构，并能被学生反复追问、测验与巩固。

---

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 图文素材智能解析 | 支持上传图片 / PDF / 课件，AI 直接看懂内容（含示意图、公式、课件文字） |
| 知识点结构化抽取 | 自动抽取知识点列表（要点 / 难度 / 所属章节），生成结构化大纲 |
| 交互式答疑辅导 | 对任意知识点多轮追问、自动出题测验、错题讲解，化身专属助教 |

结构链路：
上传教学素材 → 图文智能解析 → 知识点结构化展示 → 交互式答疑辅导

## 三、技术架构（规划）

后端服务（FastAPI / 模型接入） + 前端应用（Web / 可视化）

- LearnBuddy 智能体：承载深层解析与答疑能力，可在 LearnBuddy 平台内直接交互体验。
- Web 应用：承载上传与结构化可视化的体验，提供可在线访问的 Demo。

## 五、快速开始（Roadmap）

- 后端：pip install -r requirements.txt；uvicorn app.main:app --reload
- 前端：npm install；npm run dev

环境变量靠 backend/.env 提供（LLM_API_KEY 等，勿提交）
