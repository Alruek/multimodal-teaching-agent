## 优化：星空图星球更真实 + 修复黏连（力导向）
- 问题：弹簧系数 k=0.045*alpha 随温度衰减到近乎 0，而中心引力 0.006 为常数 → 稳定后弹簧失效、中心引力把节点拉到中心（平衡距离≈31px<节点直径），星球黏成一团。
- 修复：①弹簧改为固定 k=0.05、理想长度=r1+r2+100（不随 alpha 衰减）；②斥力加碰撞项（节点最小间距 r1+r2+24，重叠时强推开）；③中心引力从 0.006 降到 0.002（仅防漂移）；④alpha floor 0.02→0.06 保留微动。
- 数值模拟验证（3000 帧）：最小间距 gap=21.6px、重叠 0/45、边平均长度 161.5px → 彻底分散、靠线连接。
- 星球更真实：5 段立体渐变球体（白→亮→主→暗→更暗）+ 大气层光晕 + 表面纹理（陨石坑斑点，用 hashSeed 生成固定种子 + 随时间自转）+ 顶部高光 + 发光描边。
