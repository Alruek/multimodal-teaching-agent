# 知屿 ZhiYu · 腾讯云图形化部署（评委可直连，免加速器）

> 目标：让评委员用自己电脑/手机，**直接打开一个公网链接**就用上「上传 PDF/图片 + 知识点抽图 + 交互答疑」。
> 全程使用**腾讯云轻量应用服务器的宝塔面板图形化界面**，你在浏览器里点按钮即可，不强制敲命令行。

---

## 一、先解决"为什么现在要开加速器"

- 你本地 `localhost:8000` 是本机服务，**本来不需要加速器**。若"要加速器才能开"，多半是加速器开了**全局模式**把 localhost 流量也绕到国外了，关全局/加 localhost 直连规则即可。
- **真正重要**：评审要**异地、公网**访问。只要把服务托管到 **国内服务器**（腾讯云），它就有国内公网 IP，**国内任何网络（含校园网/移动流量）都能免加速直连**。DeepSeek、腾讯 OCR 本来就在国内，所以整套系统国内流畅。

---

## 二、第一步：买一台腾讯云轻量服务器（新用户很便宜）

1. 打开腾讯云官网 → 搜索「**轻量应用服务器**」。
2. 选择套餐（**新用户常 50~100 元/年**，2核2G 足够本项目）：
   - 地域选**离你/评委近的**（一般选「上海」或「广州」，作为默认即可）。
   - 镜像/系统选 **Ubuntu 22.04** 或 **宝塔面板**（若有「预装宝塔」直接选，能省一步）。
3. 下单后，服务器会分配一个**公网 IP**（形如 `124.221.8.8`），记下来。
4. 腾讯云会自动绑定默认安全组；**本项目需要额外放行 `8000` 端口**（见下文）。

> 想最省事：轻量应用自带「**应用模板：宝塔面板**」或「Docker」模板，点几下就有图形界面。

---

## 三、安全组放行（评委要能访问你的 8000 端口）

在腾讯云控制台 → 你的轻量服务器 →「**防火墙 / 安全组**」→ 添加规则：

| 方向 | 协议 | 端口 | 来源 | 说明 |
|------|------|------|------|------|
| 入站 | TCP | `8000` | `0.0.0.0/0` | 你的后端（前端同源也走这个） |
| 入站 | TCP | `443` | `0.0.0.0/0` | 若后续想上 HTTPS 用 |
| 入站 | TCP | `22` | 你的IP | SSH（默认已有） |

> 评委只要 `8000` 能通即可。若想让评审体验更好，可直接用 IP + 端口访问（见第五步）。

---

## 四、用宝塔图形化解 Docker（不敲命令）

### 1. 打开宝塔面板
- 登录腾讯云轻量 → 服务器 → 面板菜单会显示「宝塔面板」入口，点开即得一个网址+默认用户名密码。
- 宝塔里会提示你可能要装「Docker 管理器」插件，点安装。

### 2. 两种方式二选一（都只要拖拽/粘贴）

**方式 A：直接用宝塔「容器」功能导入我们编排好的项目（推荐）**

我已经在项目 `backend/` 里给你准备好了 `Dockerfile`、`requirements.txt`、`.dockerignore`，以及 `app.py` 和 `static/`（静态页面）。你只需：

1. 把整个 `backend/` 目录打成 zip 传到服务器（用宝塔的「文件→上传」）。
2. 然后在宝塔里的「终端/容器」执行：

```bash
cd /path/to/backend
docker build -t zhiyu:latest .
docker run -d --name zhiyu -p 8000:8000 \
  -e DEEPSEEK_API_KEY=你的DeepSeek密钥 \
  -e TENCENT_SECRET_ID=你的腾讯云SecretId \
  -e TENCENT_SECRET_KEY=你的腾讯云SecretKey \
  zhiyu:latest
```

（这样密钥不写进镜像，用环境变量注入，安全且评委无感知。）

**方式 B：完全图形化（不敲命令）**
若你完全不碰终端：宝塔容器面板也支持「上传 Dockerfile 自动构建 + 一键运行」，按面板提示填入上面同款环境变量即可。

> 补充：也可用宝塔的「项目管理器（Python）」，直接把本项目跑起来，需先装依赖 `pip install -r requirements.txt`。

## 五、评审怎么打开？（核心）

部署成功后，服务就在你服务器的公网 IP 的 `8000` 端口上。

### 主方式（无需备案，立即可用）
```
http://你的服务器公网IP:8000
```
例：`http://124.243.8.5:8000`

- 评委在手机/电脑浏览器直接打开即可，**无需任何加速器**。
- > 若你只有 HTTP 而评委要求 HTTPS，后续可再加（非必）。

### 进阶（可选）：绑定域名 + HTTPS（评委体验更佳）
- 需要一个**已备案**的域名（备案要实名，需你本人操作，不是几个月）。
- 备通过后在 DNS 解析到服务器 IP，腾讯云有「免费 SSL 证书」，配好即可 `https://你的域名` 并强制 HTTPS。
- **不是免得现场，可先用 IP:端口 应付答辩。**

## 六、上线前必检（照此清单一次过）

1. **`/health` 探活**：`http://IP:8000/health` 应显示 `{"status":"ok", ... }`。
2. **首页**：打开 IP:8000 应出现"知屿 · 多模态教学智能体"前端页（不是 JSON）。
3. **上传解析**：选一份 PDF/图片，应能出"知识点 + 知识图谱"，OCR 正常返回 `ocr_status:"ok"`。
4. **答疑**：上传后点几个知识节点，能收到 AI 回复。
5. **安全组**：确认 `8000` 入站已放行，否则外来访问不通。

## 五、常见情况

| 问题 | 原因 | 解决 |
|------|------|------|
| 评委打不开 `IP:8000` | 安全组没放 `8000` | 到防火墙加 `TCP 8000` |
| 打开是白屏/502 | 服务没起来或依赖没装 | 看宝塔日志 / `docker logs zhiyu` |
| OCR 返回"待接入" | 没配腾讯云 OCR 密钥 | 在 `.env` / 环境变量补 `TENCENT_SECRET_ID/KEY` |
| 被当成"要加速器" | 你把加速器全局开了 | 关全局/加白 localhost |

> 免费轻量（快眼）注意：免费额度有 CPU 运行时长限制，本项目耗资源不高，但又一堆评审同时点、或长时间并发，可能触限——**答辩前可给演示留一句"在演示忙碌环境会略慢"背书**，并对资源情况有预期。
